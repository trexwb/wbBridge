## 构建、调试与健康检查

这几项都以 `AGENTS.md` 为唯一正文，本页不再复制：

- 构建桌面应用（含 `npm run build` / `npm run tauri:build` 的链路与 updater 私钥注入包装器的取值顺序、`bundle.targets` 不含 `dmg` 与 `make:dmg` 的 hdiutil 由来、构建期两类预期告警）→ `AGENTS.md`「常用命令 › 签名与发布」（仓库级签名变量配置、报错 → 成因对照与公钥轮换约束同在该节）；发布验收相关口径见[版本与发布](版本与发布)。
- 单独运行核心（`cargo run --manifest-path src-tauri/core/Cargo.toml --bin wbbridge-core`，监听 `127.0.0.1:41980`）与健康检查（`/health` 同样需要 Bearer 鉴权，key 在数据目录 `api-key`；两种运行形态的数据目录不同）→ `AGENTS.md`「常用命令」与「核心架构与数据流」。
- 核心环境变量清单（`BUDDY_PORT` / `BUDDY_DATA_DIR` / `BUDDY_MODELS_FILE` / `BUDDY_NO_SYNC` / `BUDDY_OPENCODE_PATH` / `BUDDY_PARENT_PID` 等）→ `AGENTS.md`「常用命令 › 环境变量（核心）」。
