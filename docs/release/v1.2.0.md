# WB Bridge v1.2.0 — Release 说明

> 本文件是 `v1.2.0` Release tag 的说明文档底本，可直接作为 GitHub Release 正文。

## 版本号定版说明

本次将版本号**统一回归并定版为 `1.2.0`**。

此前在 `1.3.x` 预发线上累积的改动（AI 助手体验修复、面板与样式打磨、测试与 CI 扩充、依赖更新）不再单独以 `1.3.x` 发布，而是**一并并入 `v1.2.0` 作为单次正式发布**：`1.3.x` / `1.4.x` 段已弃用，后续推进从 `1.2.x` 起递增。版本落点共 7 处，全部校验一致（根 `package.json`、`src-tauri/tauri.conf.json`、壳 `Cargo.toml`、核心 `Cargo.toml`、`AGENTS.md` 基准表三行），可用 `npm run version:check` 复验。

---

## 主要变更

### 一、AI 助手（核心体验修复与增强）

- **流式错误兜底（壳侧）**：核心在 SSE 响应头已发出后，后续失败只能以 `data: {"error":{...}}` 补发且没有 `[DONE]`；这类帧没有 `choices`，过去会被累加器整帧吞掉，表现为「转圈结束后气泡一片空白、不报任何原因」。壳侧新增 `sse_error_of` 识别流中错误帧并 surfacing 为失败，修复了 `WB · auto` 落到慢/坏免费模型时「没有任何信息返回」的根因（含 `ai_stream_error_frame_is_surfaced_not_swallowed` 单测钉死各类帧形态）。
- **面板桥接修复（关键缺陷）**：修正 Tauri v2 事件监听解包——回调收到的是事件对象 `{event, id, payload}`，载荷在 `payload` 上；旧代码把事件对象当载荷读 `chatId` 恒为 `undefined`，导致 `ai-chunk` / `ai-done` / `ai-error` / `ai-aborted` 四类事件被整体过滤，助手每一轮都会永远转圈，连失败原因与「停止」都不可见。新增 `src/core/bridge.test.js` 钉死该事件形状与 `chatId` 过滤（`npm run test:bridge`）。
- **重试 / 重新生成**：最新一轮助手消息同时支持成功态「重新生成」与失败态「重试」，历史沿用当轮开始前的快照（不把旧回复教给模型）；工具卡片随旧气泡一起丢弃，已执行的工具副作用不回滚。
- **请求上下文最小化**：默认只带最近 6 条历史（约 3 轮问答），单条超过 4000 字符就地截断并标注；免费模型窗口小，请求越小首字越快；省略条数按完整历史计数并显式标注，避免无声断裂（`ai.test.js` 同步新语义）。
- **（既有的 1.2.0 基线能力，随本版一并确认）**：AI 助手流式对话、18 条工具表自然语言代管面板、对话记录持久化至 IndexedDB、模型就位门槛、`WB · auto` 智能路由。

### 二、面板与界面打磨

- **用量表（Usage）吸顶修复**：弃用 `border-collapse: collapse` + `overflow: hidden` 裁圆角的写法（那会把滚动容器裁在表格自身、导致 sticky 表头永远不生效），改为 `separate` + 0 间距外观一致，圆角由四角单元格各自裁切。
- **About 视图**：行距 / 内距统一改用 spacing 设计变量，阅读节奏与「WorkBuddy 集成」键值区对齐。
- **空态 / 提示框**：`padding` 规范化，与列表空态同一套语言。

### 三、测试与 CI

- 新增 `src/core/chatSession.test.js`：IndexedDB 会话存储——字段递归裁剪、落盘前丢弃工具入参（避免 `set_provider_key` 的 `args.apiKey` 明文落盘）、写盘失败静默降级。
- 新增 `src/core/bridge.test.js`（见上）。
- `release.yml` 单测套件由 5 组扩至 7 组（新增 `chat` / `bridge`），CI 闸门覆盖 `cargo test` + `check-version.mjs` + 七组 `node --test`。

### 四、依赖与工程

- `vue` `3.5.43` → `3.5.44`。
- 新增 `npm run test:bridge` 脚本。
- 两份 `Cargo.lock` 随版本回退同步（保留既有传递依赖补丁更新）。

## 安装与升级

- **全新安装**：下载对应平台的安装包（见 `docs/wiki/版本与发布.md` 的「安装包命名」表）。macOS 为 ad-hoc 签名、未做 Apple 公证，首次打开若被拦截，参见该文档「macOS 首次打开」一节（`xattr -dr com.apple.quarantine`）。
- **应用内更新**：`v1.0.2` 起支持；`v1.0.1` 及更早版本无 `.sig` / `latest.json`，需手动下载安装包升级一次。
- **更新通道**：Draft Release 发布后由维护者点 Publish 才对客户端可见（灰度闸门）；`latest.json` 由 CI 的 `update-manifest` 作业唯一写入。
