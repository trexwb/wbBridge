# WB Bridge v1.3.5 — Release 说明

> 本文件是 `v1.3.5` Release tag 的说明文档底本，可直接作为 GitHub Release 正文。

## 版本号说明

`v1.3.4` 尚未打标签（上一个已打标签并发布的版本仍是 `v1.2.5`），本版在其上做一处功能扩展：**付费模型白名单**。按「新功能 = minor」的档位规则本应落到 `1.4.0`，但 `AGENTS.md` 明确规定 `1.4.x` / `1.5.x` 段位已弃用、不得再占用，因此本版按 **1.3.5（patch）** 发布。

版本落点共 7 处（根 `package.json`、`src-tauri/tauri.conf.json`、壳 `Cargo.toml`、核心 `Cargo.toml`、`AGENTS.md` 基准表三行），已统一为 `1.3.5`，`npm run version:check` 通过。`status.json` 内写入的 `0.2.0` 是历史沿革值，不属版本落点。

## 主要变更

### 一、付费模型白名单（显式逐条放行）

免费发现按「输入 / 输出 / 缓存读写标价全 0」过滤，付费模型（例如腾讯 TokenHub 的 `hy4`）因此永远进不来。本版给用户一个**逐条**放行付费模型的入口，同时把自动路径全部挡在账单之外：

- **放行粒度是模型，不是平台**：白名单元素为**全限定 id**（`<注册表平台 id>/<模型 id>`，如 `tencent-tokenhub/hy4`），最多 64 条；平台前缀必须在 `providers::PROVIDERS` 内，跨平台的 id 一律 400 `invalid_paid_model`。
- **全量替换写入**：新动作 `POST /admin/set-paid-models`，载荷 `{ "models": string[] }`，空数组即清空；核心正在读取或探测时返回 409 `busy`。写入 `settings.json` 的 `paidModels`，并同步进程内白名单与 `status.json` 顶层 `paidModels`。
- **发现放行**：`backend::models_in(providers, namespace, allowed_paid)` 是唯一放行点，白名单条目绕过标价过滤，并在条目上标 `paid: true`；免费条目的键集不变（不带 `paid`），JS↔Rust 对拍夹具逐字节不变。放行条目照常探测、发布、进入 `/v1/models` 与插件配置，也照常计入用量。
- **自动路径一律排除**：`WB · auto` 的选择域先经 `auto::free_pool` 剔除 `paid: true`；辅助转写候选同样先经该过滤；权重耗尽的自愈重检在池内存在付费条目时直接跳过。这三处都是「不通知用户就会产生真实账单」的路径。
- **手动请求不受影响**：用户显式指定付费模型发起的请求照常转发并按平台标价计费——这正是白名单授权本身。
- **面板**：每张平台卡片新增「付费模型白名单」区（加入 / 移出、条数徽章、真实计费警示）；保存后对本平台触发一次定向 `probe { providers }`，新放行的模型在下一轮发现里出现。模型列表与详情为 `paid: true` 的行加红色「付费」徽章；AI 助手的快照与 `list_models` 同样标注付费条目，并说明 `WB · auto` 不会自动选择它们。

### 二、契约与壳侧链路

动作表由 10 条增至 **11 条**：

| 动作 | 路由 | 载荷 | 说明 |
|---|---|---|---|
| `set-paid-models` | `/admin/set-paid-models` | `{ models: string[] }` | 全量替换付费白名单；空数组清空；读取 / 探测中返回 409 |

壳侧新增类型化命令 `core_set_paid_models`，`bridge.js` 完成 `set-paid-models` 映射，`ADMIN_ROUTES` / `ACTION_ROUTES` 两侧与 `shell_action_routes_match_the_core_contract` 同步。`status.json` 的 `paidModels` 为加法式字段，`schemaVersion` 仍为 `1`。

### 三、文档

- `README.md`、`AGENTS.md`（命令清单、数据目录表、核心特例约束、数据红线）、`docs/contract.md`、`docs/wiki/架构设计.md`、`docs/wiki/核心概念与功能.md`、`docs/wiki/使用指南.md` 同步至 11 条动作与付费白名单语义。
- 修正两处陈旧描述：平台视图早已接入（不再是「面板还没有入口视图」）；平台注册表为九家（不再是「四家」）。

## 已知限制（本版相关）

- 白名单只认注册表平台的命名空间；`opencode` 自带命名空间不支持放行付费条目。
- 放行 = 真实计费。探测本身也会消耗平台额度；面板的警示文案不替代用户对平台定价的确认。
- 白名单条目仍受探测判定约束：探测失败 / 超时的模型不会进入发布集，与免费模型同规则。
- Windows / Linux 实机、自动更新客户端升级闭环、商业签名 / 公证等既有未验证项不变。

完整边界见 [`docs/wiki/已知限制与未验证项.md`](../wiki/已知限制与未验证项.md)。
